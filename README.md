# Личная CRM

Приложение, где я веду контакты людей, которых знаю лично. Подробности — в `specs/01-продуктовая-идея.md`.

## Что умеет

- Список всех контактов по алфавиту, с разбивкой по буквам
- Поиск по имени: по части имени, без учёта регистра, «е» и «ё» не различаются («семен» найдёт «Семёнов»)
- Добавление контакта: имя, кто это, откуда знакомы, телефон, почта
- Карточка контакта: все поля, кнопка «Изменить» и заметки с датой — что обсудили и о чём договорились
- Данные хранятся в базе PostgreSQL, поэтому в любом браузере на этом компьютере видны одни и те же контакты

Приложение открывается только на этом компьютере: входа по паролю нет, поэтому из сети (например, из того же Wi‑Fi) оно недоступно.

## Как запустить

### Что нужно

- Docker (OrbStack или Docker Desktop) — должен быть запущен
- Node.js 24 и pnpm

### Первый запуск

1. Создай файл с настройками из шаблона и заполни значения:

   ```bash
   cp .env.example .env
   ```

   Пароль — любая длинная случайная строка, например из `openssl rand -hex 24`.
   `DATABASE_URL` собирается из тех же значений, формат указан в шаблоне.

2. Запусти базу:

   ```bash
   docker compose up -d
   ```

   Проверь, что она работает: `docker compose ps` — в колонке `STATUS` должно быть `healthy`.

3. Установи зависимости и создай таблицы в базе:

   ```bash
   pnpm install
   pnpm db:migrate
   ```

4. По желанию — заполни базу тестовыми данными (1000 выдуманных контактов с заметками):

   ```bash
   pnpm db:seed
   ```

   Команда ничего не удаляет и не перезаписывает: если в базе уже есть контакты, она просто ничего не сделает.
   Все люди выдуманные, почты — на служебных доменах `example.com`, письмо на них никуда не уйдёт.

5. Собери и запусти приложение:

   ```bash
   pnpm build
   pnpm start
   ```

   Открой в браузере: <http://localhost:3000>. Остановить — `Ctrl+C` в терминале.

### Следующие запуски

```bash
docker compose up -d   # если база не запущена
pnpm start             # если код не менялся; после изменений сначала pnpm build
```

## Как проверить главный сценарий руками

1. Открой <http://localhost:3000> — видно список всех контактов и их число
2. Нажми «Добавить контакт», заполни имя, нажми «Добавить контакт» — откроется список, новый контакт подсвечен зелёным
3. Начни вводить его имя в поиске — список отфильтруется
4. Открой контакт, напиши заметку, нажми «Добавить заметку» — заметка появится ниже с датой
5. Обнови страницу — заметка на месте
6. Открой тот же адрес в другом браузере (например, Safari) — те же контакты и та же заметка

## Для разработки

- `pnpm dev` — режим разработки: изменения в коде видны сразу, но страницы открываются медленнее
- `pnpm lint` и `pnpm typecheck` — проверка кода
- `pnpm db:generate` — после изменения схемы в `src/db/schema.ts` создаёт новую миграцию в папке `drizzle/`, затем `pnpm db:migrate` применяет её

Где что лежит:

- `src/app` — страницы: список (`page.tsx`), новый контакт, карточка, редактирование; `actions.ts` — сохранение данных
- `src/db` — схема таблиц, подключение к базе, запросы
- `src/components` — формы, поиск и другие части интерфейса
- `scripts` — заполнение базы тестовыми данными

## Полезные команды для базы

- Остановить базу: `docker compose stop` — данные сохранятся
- Запустить снова: `docker compose up -d`
- Открыть консоль базы: `docker compose exec db psql -U personal_crm -d personal_crm` (выход — `\q`)
- **Осторожно:** `docker compose down -v` удаляет базу вместе со всеми данными
