# Макет «Пора связаться»

Живой макет: https://claude.ai/artifact/PQh8XcQaYKkE4Q5n6yXa1b — открывается только у владельца. Здесь лежит копия его файлов на 24.10.2026: сами по себе в браузере они не открываются, им нужна страница макета. Копия нужна, чтобы при реализации было видно точную разметку, цвета и тексты.

Если макет и требования (`../specs/keep-in-touch/spec.md`) расходятся, правы требования.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Главная, компьютер: розовый блок «пора связаться.exe» над списком, галочки в строках, уведомление с «Отменить» |
| `CardDesktop.dc.html` | Карточка контакта, компьютер: строка «Как часто общаться», красная просрочка, кнопка «Пообщались» |
| `EditDesktop.dc.html` | Форма «Изменить контакт», компьютер: шесть вариантов частоты и поле числа дней для своего срока |
| `MainPhone.dc.html` | Главная, телефон |
| `CardPhone.dc.html` | Карточка контакта, телефон: галочка без подписи |
| `NewPhone.dc.html` | Форма «Новый контакт», телефон: свой срок и ошибка в числе дней |
| `canvas.json` | Как экраны разложены на холсте макета |

В макете можно переключать состояния (кнопка Tweaks у экрана): «Никто не просрочен» на главной, три состояния карточки, примеры формы со своим сроком и с ошибкой, показ уведомления.
