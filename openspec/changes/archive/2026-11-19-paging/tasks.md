# Tasks

Каждая задача — сначала тест: написать, запустить, увидеть красным, потом код, тест зелёный. Сценарии спеки, которые уже выполняются до задачи, остаются тестами-сторожами; это отмечено у задачи. Каждый сценарий из `specs/` — отдельный тест или шаг теста, названный по сценарию: браузерные тесты идут путями пользователя, как в остальных `e2e/*.spec.ts`. Путей немного не случайно: каждый тест входит в приложение заново, а вход пропускает не больше 100 запросов в минуту на все тесты вместе.
